# Admin Panel - Perfect Air Solution

Modern, responsive Admin Panel for managing Perfect Air Solution HVAC services, blogs, brand partners, project installation gallery, and customer inquiries.

## Features
- **Dashboard**: High-level statistics overview with quick metrics.
- **Blogs**: CRUD management for articles and guides with pagination.
- **Brands**: Partner logo management with interactive pagination.
- **Gallery**: Pure photo installation showcase with lightbox zoom & left/right keyboard navigation.
- **Contact Inquiries**: Real-time customer lead tracker with status toggles and direct WhatsApp/call/email actions.

## Tech Stack
- React + TypeScript + Vite
- Tailwind CSS
- Lucide React Icons
- Redux Toolkit Query

## Getting Started
```bash
npm install
npm run dev
```
